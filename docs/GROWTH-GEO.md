# 获取第一批用户 + GEO / SEO 策略

## 定位

不是“AI 新闻站”。

核心一句话：

> 帮高频 Codex / ChatGPT Work 用户不错过值得行动的额度 Reset，并把时间统一换成北京时间。

这个定位越窄，首批用户越容易理解为什么要订阅。

## 首批用户渠道

优先顺序：

1. 你自己长期使用并截图真实提醒体验。
2. X / GitHub / V2EX / 即刻 / 小红书 / B站等发布“解决问题”的内容，而不是硬广告。
3. 每次真实 Reset 后做一张：原帖 → 北京时间 → 如何判断 → 结果。
4. 写 3-10 篇高质量 evergreen 指南。
5. 让用户把提醒链接分享给同样用 Codex 的朋友。

不要首月就大规模付费投流。

## GEO 的核心不是“骗 AI 排名”

目标是让搜索与 AI 系统更容易：

- 确认这个页面在回答什么；
- 找到简洁答案；
- 找到证据和来源；
- 理解实体关系；
- 判断内容新鲜度。

当前仓库已经提供：

- FAQ JSON-LD
- Article JSON-LD
- Organization / SoftwareApplication JSON-LD
- sitemap.xml
- robots.txt
- llms.txt
- RSS
- IndexNow
- Canonical
- 清晰专题 URL
- 原始来源链接
- Reset 实时数据页

## 内容模板

每篇内容回答一个真实问题：

### 标题
用户真的会问的完整问题。

### 前 100 字
直接给答案，不卖关子。

### 证据
原始来源 / 实际例子 / 时间。

### 解释
为什么这样判断。

### 行动
用户下一步应该做什么。

### 更新时间
时间敏感内容必须标注更新。

## 首批 Topic Cluster

核心页：
- Codex Reset 时间线

支持页：
- Codex Reset 是什么
- Banked Reset 是什么
- PT / PST / PDT 转北京时间
- 如何查看 Codex 剩余额度
- Reset 前应该做什么
- Work 与 Codex 的额度关系（必须按最新官方资料维护）
- 为什么 Scheduled 不等于 Completed

不要自动生成几百个城市词 / 长尾词页面。

## 衡量 GEO

不要只看传统排名。

记录：
- Google/Bing 搜索自然流量；
- AI referral；
- Bing AI Performance 可获得后关注 citation / grounding query；
- 用户在 ChatGPT / Copilot / Perplexity 等看到引用后进入站点的来源；
- 哪些 FAQ/指南带来订阅转化。

最终优化目标仍然是“帮助用户解决问题并订阅”，而不是 citation 数字本身。
