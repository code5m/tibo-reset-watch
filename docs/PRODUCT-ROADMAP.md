# 产品路线图

## Now — 能上线验证

- Tibo Reset 可靠监控
- 北京时间转换
- 创始人微信告警
- 网站首页
- Reset 时间线
- 项目雷达
- 免费订阅
- Admin 工作台
- 用户管理
- 内容管理
- Campaign 管理
- Email / WeChat / SMS / Alipay Adapter
- 自动 Reset Campaign
- 发送审计
- FAQ / Guides / Sitemap / RSS / IndexNow / llms.txt
- 退订

成功标准：
有真实用户因为提醒“及时且有用”而持续订阅。

## Next — 10~100 个真实活跃用户后

- 用户自助管理通知偏好
- 邮箱验证 / 手机验证
- 更正式的公众号 / 企业微信通道
- 正式短信供应商
- 点击 / 打开追踪
- Campaign 预览与测试发送
- Content 编辑 / 版本管理
- 多来源 AI usage intelligence
- 数据导出
- 用户反馈入口

## Later — 证明付费意愿后

- Pro 付费订阅
- Team Workspace
- 自定义监控源
- Webhook / API
- 规则化通知
- 多成员 / RBAC
- 企业 SLA
- 微信支付 / 支付宝支付
- 发票 / 退款 / 客服体系

## 不要现在做

- 大型推荐算法
- 复杂 AI Agent 自动发文
- 100 个社交平台适配
- 没有用户的多租户微服务
- 为“看起来像大公司”提前拆几十个服务

第一次创业最容易死在“做得太多，但没人用”。
