# Growth & Distribution Playbook

核心增长闭环：公开事件 → 可索引网页 / RSS → 社交平台内容 → 落地页 → 微信 / 支付宝 / 短信订阅 → 高价值通知 → 用户分享。

P0：GitHub、X、RSS、V2EX / Linux.do。
P1：中国侧微信公众号、知乎、小红书、B站、掘金/CSDN。

## 标准分发包
标题：Codex Reset：{ANNOUNCED/COMPLETED/BANKED}｜北京时间 {时间}

正文必须包含状态、北京时间、明确适用范围、一句话中文解释、Tibo 原始 X 链接、订阅入口。严禁把预计写成完成，严禁把第三方推测冒充 Tibo 官方确认。
